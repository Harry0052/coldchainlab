# Security

ColdChainLab does not accept credentials and does not connect to a network service at run time.

Report a vulnerability through GitHub private vulnerability reporting:

https://github.com/Harry0052/coldchainlab/security/advisories/new

Do not open a public issue for an unpublished security report.

This project is a synthetic training drill. It is not a medical device, and it does not provide storage, handling, or product-disposition advice.
